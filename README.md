# L’IA en schémas

Support visuel que le formateur projette pour expliquer l’IA générative : une notion, une planche, un grand schéma SVG presque sans texte. 39 planches, 9 chapitres, 3 parties. Site statique (`site/`) publié sur GitHub Pages.

```
npm install
npm start          # http://localhost:4180
npm run check      # Prettier + validation HTML
npm test           # Playwright (mise en page, thèmes, axe, projection)
npm run captures   # PNG de chaque planche dans captures/
```

Voir [AGENTS.md](AGENTS.md) pour les règles et la façon d’ajouter une planche ou un chapitre.
